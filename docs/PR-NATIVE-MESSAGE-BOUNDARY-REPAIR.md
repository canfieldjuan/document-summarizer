## Root cause
The native request represents complete framed tokens but discards the message-boundary metadata that accompanies equivalent chat framing. CompletionRequest at src-tauri/src/pipeline/llama_cpp.rs:2090, built at :585, has no message_delimiters field. Introducing native-design commit446dd3b4 already omitted it; the later capture refactor did not introduce it. PromptFraming (:112, load at :1455) is the existing native owner of Qwen control framing. Every native generate_with_control call reaches completion (:767).

The pinned server chat projector attaches delimiters at tools/server/server-common.cpp:1350. The native route defaults absent delimiters to empty (:4177), tokenizes them (:4179), and assigns message_spans (:4193). Its eligible batch branch uses the user boundary (:3434). The shared native port therefore lost execution-relevant framing information before inference. A request-origin repair is required; output rewriting cannot restore the missing input.
